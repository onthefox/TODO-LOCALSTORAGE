# TODO-LOCALSTORAGE

Простой TODO-менеджер на чистом JavaScript, который хранит данные в `localStorage`. Без сборки, без зависимостей — откройте `index.html` и работайте.

## Возможности
- **Задачи**: добавление, редактирование, удаление, отметка о выполнении
- **Теги**: пишите `#тег` в тексте задачи — тег извлекается автоматически; клик по тегу фильтрует список
- **Дедлайны**: необязательная дата выполнения; бейджи `⚠ просрочено`, `📍 сегодня`, `📅 дата`
- **Фильтры**: Все / Активные / Выполненные + фильтр по тегам
- **Сортировка**: вручную (drag-and-drop или стрелки), сначала новые, сначала старые, по алфавиту
- **Массовое удаление** выполненных задач
- **Отмена (undo)**: удаление, массовая очистка и импорт можно отменить в течение 10 секунд
- **Импорт/экспорт JSON**: резервная копия одним кликом; импорт с валидацией данных
- **Тёмная тема**: авто (следует за системой) / светлая / тёмная, с запоминанием выбора
- **Доступность**: aria-метки, `role=status` для счётчика, видимый фокус, поддержка `prefers-reduced-motion`

## Горячие клавиши
- `Alt + ↑` / `Alt + ↓` — переместить задачу выше/ниже (в режиме «Вручную»)
- `Enter` / `Space` на тексте задачи — отметить выполненной
- Drag-and-drop за «ручку» ⠿ — перетаскивание задач

## Формат хранения (v2)
```json
{
  "version": 2,
  "tasks": [
    { "id": "…", "text": "Текст задачи", "completed": false, "createdAt": 1700000000000, "tags": ["работа"], "due": "2025-06-01" }
  ]
}
```
Ключ: `todo-localstorage-tasks`, тема: `todo-theme` (`auto` | `light` | `dark`).

Данные старых версий мигрируют автоматически: текст из v1 хранился HTML-экранированным (`&amp;` и т.п.) — при загрузке он декодируется; массивы без обёртки (v0) тоже поддерживаются. Текст хранится «как есть» и экранируется только при рендере (`textContent`), поэтому HTML/скрипты в тексте задачи безопасны.

Ограничения: до 5000 задач, текст задачи — до 500 символов, при импорте данные валидируются (некорректный файл будет отклонён).

## Структура
- `src/core.js` — чистый слой данных (парсинг тегов, миграции, фильтры, сортировка, порядок, дедлайны). Без DOM, тестируется отдельно.
- `src/app.js` — контроллер: хранилище, действия, undo, тема, рендер.
- `src/index.html` — интерфейс (CSP: `script-src 'self'`, без инлайновых скриптов).
- `src/styles.css` — стили: светлая/тёмная темы через CSS-переменные, адаптивность.
- `src/test.html` + `src/test.js` — браузерный тестовый набор.

## Тесты
Откройте `src/test.html` — около 40 проверок покрывают слой данных (парсинг тегов, миграции, валидацию импорта, фильтры, сортировку, reorder, дедлайны) и контроллер (хранилище v2, undo, тему, XSS-безопасность рендера). Результат виден на странице; итоги также публикуются в `window.TestResults`.

Логические проверки `core.js` можно прогнать и без браузера: файл чистый (без DOM), все экспорты — функции верхнего уровня.
