# TODO-LOCALSTORAGE

Простой TODO‑менеджер, который хранит данные в localStorage.

## Функциональность MVP
- Добавление задач
- Удаление задач
- Отметка о выполнении
- Сохранение в localStorage
- Загрузка при старте

## Стек
- HTML
- CSS
- JavaScript (без фреймворков)

## Запуск
Откройте файл `index.html` в браузе.
