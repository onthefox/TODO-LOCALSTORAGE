# Техническая спецификация TODO-LOCALSTORAGE

## Структура задачи

```js
Task {
  id: string       // уникальный идентификатор
  text: string     // текст задачи
  completed: bool  // выполнена ли задача
  createdAt: number// timestamp создания
}
```

## Операции

- Добавление задачи
- Удаление задачи
- Отметка о выполнении/снятие отметки
- Загрузка/сохранение в localStorage при каждом изменении

## localStorage

- Все задачи хранятся в одном ключе: 'todo-localstorage-tasks'
- Формат хранения: JSON-массив из объектов Task

## Ограничения

- Нет авторизации
- Нет серверной части
- Максимальный размер данных = ограничения localStorage браузера (~5 МБ)
